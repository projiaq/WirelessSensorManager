# 待确认问题

1. `sensor_id` 的正式来源和各类型允许范围是什么？当前传感器固件不提供该字段，接收器仅要求非零（接收器 `app.c:1565-1566`）。App 暂允许人工选择 1..255。
2. 压力结果的正式工程单位是什么？`app_pressure.c:145-159` 的公式与旧界面“bar”描述缺少冻结的协议定义。App 不换算。
3. 接收器 39 字节 Notify 在 MTU 协商失败时的预期行为是什么？固件未定义应用层分片或降级读取流程。
4. Device Information 中 Receiver 的 model/hardware 字符串由何处生产写入？GATT 默认值不能视为正式硬件版本。
5. 是否需要限制一个传感器只能属于一个接收器？现有传感器固件不保存该关系，无法跨接收器可靠判定。
6. 自定义 GATT 当前无认证、加密或 bonding。量产是否需要安全要求？这将涉及固件变更，当前 App 不自行添加不兼容握手。
7. 传感器 MAC 写入会立即复位（传感器 `app.c:601-609`），量产是否允许 App 开放？首版有意不开放。
8. 接收器手工广播未携带 Service UUID 或厂商类型字段，只能靠名称发现候选。建议固件在广播或 Scan Response 增加 Receiver Service UUID/稳定类型字段；修改前需用户确认。
